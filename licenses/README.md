# 第三方来源与许可

- OneDC：作者官方仓库 `onedc-codec/onedc`，整体 CC BY-NC-SA 4.0，原文在 `upstream/onedc/LICENSE.md`。原 README 另说明其 DMD2、VQGAN、DCVC 组件分别适用的条款。
- Stable Diffusion 1.5：CreativeML Open RAIL-M；对应许可全文随本目录提供。权重为已有恢复包中的原始缓存。
- Stable Diffusion 2.1 VAE：CreativeML Open RAIL++-M；对应许可全文随本目录提供。原缓存的占位 revision 不构成上游版本认证。
- TAESD：madebyollin/taesd，MIT；许可全文随本目录提供。
- AlexNet/VGG16：PyTorch/Torchvision 公共模型缓存；Torchvision BSD 3-Clause 文本随本目录提供，并保留预训练来源的适用条件。
- Kodak 图像：历史任务使用的公开 Kodak 测试集原始 PNG，只为精确恢复评测输入保留；其原始版权不因收录而改变。参考来源 <https://r0k.us/graphics/kodak/>。

具体许可文件的取得 URL、SHA-256 与状态见 `sources.json`。使用和再分发须保留各自许可及用途限制；本仓库没有将这些模型改为统一宽松许可证。
